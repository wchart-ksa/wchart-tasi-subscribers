# README بالعربية — مشروع «مشتركين منصة دبليوشارت تاسي»

## 0) نظرة عامة
نظام ويب بسيط لإدارة مشتركين المنصة:
- تسجيل مستخدم جديد + رسالة ترحيب
- تفعيل الحساب بكود من ورقة `code_1` (يصبح الكود `مستخدم` لمرة واحدة)
- لوحة مستخدم مع حالة الاشتراك والأيام المتبقية
- نسيت كلمة السر: إرسال رمز ٦ أرقام إلى البريد المسجّل عبر Gmail SMTP (كلمة مرور التطبيق)
- لوحة أدمن كاملة: إحصائيات، قائمة المشتركين مع بحث/فلترة/تصدير CSV، تمديد اشتراك، تعطيل/إعادة تفعيل، ملاحظات، إدارة الأكواد، إعادة تعيين كلمة سر مشترك، إضافة/تغيير كلمة سر أدمن
- واجهة عربية RTL متجاوبة مع الوضع الفاتح/الداكن
- بيانات محفوظة في ملف Excel واحد (`subscribers_1.xlsx`) — لا يوضع داخل مجلد عام
- قفل + حفظ آمن + نسخة احتياطية يومية
- تشفير كلمات السر (bcrypt) مع توافق للـ SHA-256+scrypt القديم
- حماية CSRF، حدود محاولات، تسجيل كامل في `Logs`

## 1) المتطلبات
- Python 3.10 أو أحدث (تم الاختبار على 3.13)
- pip
- حساب Gmail مع «التحقق بخطوتين» مفعل + «كلمة مرور التطبيق» (App Password)
- ملف Excel الأصلي موجود: `subscribers_1.xlsx` في جذر المشروع

## 3) الإعداد المحلي
### ٣.١ إنشاء بيئة افتراضية (اختياري لكن مُستحسن)
```bash
# ويندوز (cmd)
py -m venv .venv
.venv\Scripts\activate

# أو PowerShell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
```

### ٣.٢ تثبيت المتطلبات
```bash
pip install -r requirements.txt
```

### ٣.٣ إعداد متغيرات البيئة
انسخ `.env.example` إلى `.env` وعدّل القيم:
```bash
copy .env.example .env  # cmd
# أو cp .env.example .env
```

أهم القيم:
- `SECRET_KEY` — ولّد قيمة عشوائية طويلة: `python -c "import secrets; print(secrets.token_hex(32))"`
- `ENV` — `development` للتشغيل المحلي (كوكي غير آمن مفعّل للتسهيل) أو `production` للنشر مع HTTPS
- `SMTP_USER`, `SMTP_PASSWORD` — بريد Gmail + App Password
- `DATA_FILE=subscribers_1.xlsx` (لا تغيّره إلا إن نقلت الملف)
- `BACKUP_DIR=backups`

### ٣.٤ إنشاء حساب الأدمن
نفّذ السكربت مرة واحدة:
```bash
python scripts/create_admin.py
# أو مخصص:
python scripts/create_admin.py --username admin --phone 0504169042 --email wchart.ksa@gmail.com --password AdminPass123
```

### ٣.٥ تشغيل التطبيق محليًا
```bash
python app.py
```
افتح المتصفح: http://127.0.0.1:5000

## 4) ربط Gmail بـ App Password
1. فعّل «التحقق بخطوتين» لحساب `wchart.ksa@gmail.com` من إعدادات Google.
2. اذهب إلى `الحساب > الأمان > كلمات مرور التطبيق` (App passwords).
3. أنشئ كلمة مرور جديدة للتطبيق «Mail» والنظام «Other (custom name)» مثلاً `wchart-tasi`.
4. انسخ كلمة المرور (16 حرفًا بدون مسافات) وضعها في `.env` كـ `SMTP_PASSWORD`.
5. تأكد أن `SMTP_USER=wchart.ksa@gmail.com` و `SMTP_PORT=587` و `SMTP_HOST=smtp.gmail.com`.

> ملاحظة: في حال تعذّر الإرسال، سيعرض النظام رسالة واضحة بالتواصل عبر واتساب بدلاً من تعطيل المسار.

## 5) النشر على استضافة مناسبة (مع HTTPS)
يفضل استخدام خادم إنتاجي خلف HTTPS:
- على Windows يمكنك استخدام `waitress` (مُثبت بالفعل):
  ```bash
  python -m waitress --host 0.0.0.0 --port 5000 app:app
  ```
- على Linux يمكنك استخدام `gunicorn` مع `nginx` عكسي:
  ```bash
  gunicorn -w 2 -b 127.0.0.1:5000 app:app
  ```

متطلبات النشر:
- رفع كامل المشروع عدا `.venv` و `__pycache__` وملف `.env` (ضع `.env` على السيرفر مباشرة)
- ضبط `ENV=production` لضمان `SESSION_COOKIE_SECURE=True`
- التأكد من صلاحية ملف `subscribers_1.xlsx` وصلاحيات الكتابة للمجلد
- تشغيل خلف HTTPS دائماً (ضروري لكوكي الجلسة الآمن)
- لا تضع ملف `subscribers_1.xlsx` داخل أي مجلد عام يُمكن الوصول إليه مباشرة من المتصفح

## 6) الأمان والخصوصية
- كلمات السر تُخزّن بـ bcrypt. عند نجاح التحقق بصيغة قديمة (SHA-256+scrypt) يتم الترقية تلقائياً.
- رقم الجوال للعرض فقط ولا يمكن تعديله من قبل المستخدم أو الأدمن.
- تعطيل الحساب = تغيير الحالة إلى `معطل` فقط، دون حذف أي صف أو بيانات.
- حماية CSRF على جميع نماذج POST.
- تحييد القيم التي تبدأ بـ `= + - @` قبل الكتابة في Excel/CSV.
- حدود: ٥ محاولات دخول فاشلة → حظر ١٥ دقيقة، ٥ محاولات تفعيل خاطئة → حظر ١٥ دقيقة، ٣ طلبات استعادة في الساعة، ٥ محاولات رمز خاطئة → حظر ١٥ دقيقة.
- كل الأحداث تُسجّل في ورقة `Logs` مع التاريخ والفاعل والإجراء والهدف والتفاصيل والنتيجة.
- أول حساب أدمن يُنشأ فقط عبر `scripts/create_admin.py` — لا يوجد تسجيل عام يمنح صلاحية أدمن.

## 7) قائمة اختبارات سريعة
- [ ] تسجيل جديد → رسالة ترحيب تظهر بالشعار واسم المستخدم وزر دخول + واتساب/بريد
- [ ] منع تكرار: جوال/بريد/اسم مستخدم موجود مسبقًا
- [ ] تسجيل دخول غير مفعل → يُوجّه لصفحة التفعيل
- [ ] تفعيل بكود صحيح → حالة تصبح `مفعل` + انتهاء بعد ٣٠ يوم + الكود يصبح `مستخدم`
- [ ] تفعيل بكود مستخدم → رسالة خطأ واضحة
- [ ] انتهاء الاشتراك → عند دخول المستخدم يُحوّل إلى `منتهي` ويمكن إعادة التفعيل بكود جديد
- [ ] تعطيل حساب من المستخدم → يتطلب كلمة السر الحالية، يُسجّل `disabled_at`
- [ ] محاولة تغيير رقم الجوال في النموذج → حقل للعرض فقط (readonly)
- [ ] نسيت كلمة السر: طلب برقم موجود → يُظهر رسالة موحدة ويُرسل رمز إن وُجد بريد
- [ ] نسيت كلمة السر: رمز صحيح + كلمة سر جديدة → تغير بنجاح ويُلغى الرمز
- [ ] نسيت كلمة السر: رمز خاطئ/منتهي → رسائل مناسبة + حدود
- [ ] دخول مستخدم عادي لمحاولة دخول `/admin/*` → يُرفض بـ 403 وتُسجّل في Logs
- [ ] أدمن: تمديد اشتراك ساري المفعول → يضاف للأيام الحالية
- [ ] أدمن: تمديد اشتراك منتهي → يحسب من اليوم ويصبح `مفعل`
- [ ] أدمن: تعطيل/إعادة تفعيل مشترك بدون حذف بيانات
- [ ] أدمن: تصدير CSV مع BOM + تحييد خلايا `= + - @`
- [ ] التذييل يظهر في كل الصفحات (دخول/تسجيل/مستخدم/أدمن)
- [ ] الوضع الفاتح/الداكن يعمل ويُحفظ
- [ ] شعار SVG يظهر في الترويسة وبصفحات الدخول/التسجيل ويتكيّف مع الثيم

## 8) ملاحظات مهمة
- ملف `subscribers_1.xlsx` هو المرجع الوحيد للبيانات. أي تعديل يدوي يجب أن يحافظ على أسماء الأوراق والأعمدة تمامًا.
- النسخ الاحتياطية تحفظ تلقائياً في `backups/` يومياً قبل أول كتابة، ويُحتفظ بآخر ٣٠ نسخة.
- في وضع `development` (`ENV=development`) قد يسمح الكوكي غير الآمن للتشغيل المحلي؛ لا تستخدم هذا الوضع خلف HTTP حقيقي.
- السكربت `create_admin.py` يُنشئ أدمنًا نشطًا حتى تاريخ بعيد جدًا (`2099-12-31`) لسهولة الإدارة.
